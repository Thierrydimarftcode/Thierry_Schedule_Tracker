# 🚀 Thierry Task & Schedule Tracker

Aplikasi web interaktif dan responsif untuk mengelola **Jadwal Pelajaran**, **Daftar Tugas Sekolah**, dan **Agenda Kegiatan** secara efisien. Dirancang dengan tampilan modern bertema *dark mode* serta dilengkapi dengan penyimpanan lokal (*LocalStorage*).

---

## 🌟 Fitur Utama

- **📅 Manajemen Jadwal Pelajaran**:
  - Filter jadwal berdasarkan hari (Senin - Sabtu)[cite: 1].
  - Menampilkan waktu, mata pelajaran, dan lokasi ruangan[cite: 1].
  - Tambah, edit, dan hapus jadwal pelajaran[cite: 1].

- **📝 Pengolah Tugas Sekolah**:
  - Pengelompokan tugas berdasarkan skala prioritas (Tinggi, Sedang)[cite: 1].
  - Indikator hitung mundur (*countdown*) sisa waktu *deadline*[cite: 1].
  - Peringatan otomatis jika *deadline* terlewat atau mendekati[cite: 1].
  - Filter tugas berdasarkan status (Semua / Belum Selesai)[cite: 1].

- **🗓️ Agenda & Kegiatan**:
  - Mencatat kegiatan mendatang lengkap dengan tanggal, waktu, dan lokasi[cite: 1].
  - Fitur tambah, ubah, dan hapus agenda[cite: 1].

- **💾 Penyimpanan Lokal (LocalStorage)**:
  - Semua data jadwal, tugas, dan agenda tersimpan otomatis di browser tanpa khawatir hilang saat halaman diperbarui[cite: 1].
